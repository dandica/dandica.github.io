# David Sahagun — Portfolio website

A responsive, accessible, static personal portfolio. No framework, installation, paid hosting, tracking, analytics cookies, or external font requests required.

## Preview on your computer

Open `index.html` in a browser. Keep `styles.css` and `favicon.svg` in the same folder.

## Publish free with GitHub Pages (user site)

1. Log in to your **own** GitHub account. If you do not have one yet, create a free account.
2. Click **New repository**. Name it **`YOUR-USERNAME.github.io`** using your exact GitHub username. Make it public and create the repository.
3. Use **Add file → Upload files** to upload the *contents* of this folder into the repository root, including `index.html`, `styles.css`, `favicon.svg`, and `.nojekyll`. You can upload `README.md` as well. Do **not** upload only the `.zip` file.
4. Click **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
6. When GitHub finishes publishing (sometimes up to 10 minutes), open **`https://YOUR-USERNAME.github.io/`** and test the links on desktop and mobile.
7. Use that full URL in the employer's **Other website** field; you can retain the team repository link in the optional GitHub field if appropriate, clearly recognizing it is a team repository.

Official instructions: https://docs.github.com/en/pages/quickstart

## Before publishing — important review

- Verify that `https://www.linkedin.com/in/david-sahagun-ucd/` is your exact public LinkedIn URL. It was provided in a screenshot and could not be independently loaded during drafting.
- This is a **public** website. It includes your name, university, public-interest career narrative, academic projects, and email address; it **does not** publish your phone number, GPA, transcripts, or home address.
- All project content is explicitly labeled academic. The underwater-gate metrics are **team results**, not independent professional work, and links point to the team's repository hosted by a colleague.
- The diagram of the gate is **illustrative**, not taken from the project dataset.
- Review the headline and statements in your own voice before publishing.
- There is deliberately no public download of your résumé, as an employer-specific résumé may include your phone number and job-specific positioning. You can add a reviewed public PDF later.
